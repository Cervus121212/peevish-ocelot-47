Entry for the [make.fun](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) bounty **"Make the AI Judge Laugh: Cat Reviews Its Human"**.

`main.py` (Python stdlib only, deterministic) writes a single line — a one-star review from a house cat about its human — to `/output/entry.txt`:

> One star. He sits on my water bowl for forty minutes every morning, scrolling. I have to drink from the sink like an animal.

Run it with `python3 main.py` (writes to `/output` by default, or set `MAKEFUN_OUTPUT_DIR`).
